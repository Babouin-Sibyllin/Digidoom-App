# Digidoom - ENGLISH
Digidoom is a software that lets you quickly find back a digidot's IP address without any effort. Simply connect your computer via ethernet to the digidot and launch the program. A window will open in your default set browser displaying the digidot's menu.

# Digidoom - FRANÇAIS

Digidoom est un logiciel qui vous permet de retrouver rapidement et sans effort l'adresse IP d'un digidot. Il vous suffit de connecter votre ordinateur au digidot via Ethernet et de lancer le programme. Une fenêtre s'ouvrira dans votre navigateur par défaut et affichera le menu du digidot.

## Installation
### Étape 1

Cliquez sur la version de l’application située juste en dessous de « Releases ».

<img
  src="https://github.com/user-attachments/assets/19c315a2-f8f2-488a-aabb-dd571cb00d5f"
  alt="Etape 1"
  width="700"
  style="border: 2px solid #808080; border-radius: 4px;"
/>

### Étape 2

Faites défiler la page vers le bas jusqu’à ce que vous voyiez « Digidoom-Setup.exe ». Cliquez dessus; le fichier exécutable devrait se télécharger automatiquement.

<img
  src="https://github.com/user-attachments/assets/4e782213-e385-4814-8c0e-51d0fce082ab"
  alt="Etape 2"
  width="700"
  style="border: 2px solid #808080; border-radius: 4px;"
/>

### Étape 3
